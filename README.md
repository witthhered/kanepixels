A-SYNC FOUNDATION WEBSITE
=========================

ABOUT
A-Sync is an independent spatial research institute (Project KV31).
This website has two goals:
SALES - present our technology and let customers place an order.
EMPLOYEE PLATFORM - a useful internal space for our staff:
-a photo gallery,
-a research archive,
-an application platform where employees can send applications.


PAGES
-----
index.html       Home page: hero, "wonders of science" carousel, about us,
                 technology / complex / archive previews, news and updates.
tech.html        Technology: Low-Proximity Magnetic Distortion System,
                 subsystem specifications and safety protocols.
complex.html     The Complex: the new space and why we need it.
research.html    Archive: technical notes, mapping reports, field
                 observations and project records.
personnel.html   For Personnel: employee area and application sender.
place_order.html Place Order: sales page for customers.
mediamans.html   Gallery: responsive photo grid (3x2 desktop, 2x3 tablet, 1 column mobile).
media.html   Extra media page.


FOLDERS
-------
css/
style.css basic styles for mediamans.html, index.html and tech.html
isa.css and media-queries.css basic styles for complex.html, place_order.html and media.html
danik.css basic styles for research.html, poresonnel.html
assets/ Images (logo, portal, facility, prototype, gallery photos).


TECHNOLOGY
----------
- HTML5 and CSS3
- Bootstrap 5.3.3 (loaded from CDN): grid, spacing utilities, navbar,
  buttons, carousel
- Custom CSS media queries for typography and the gallery grid
- Font: IBM Plex Sans Condensed (Google Fonts)

Bootstrap and the font load from the internet, so an internet connection
is required to see the full design.


BREAKPOINTS
-----------
Mobile   under 768px
Tablet   768px and up
Desktop  1200px and up


HOW TO RUN
----------
1. Go to https://witthhered.github.io/kanepixels/
2. Use the navigation bar to move between pages.
3. To swap media page click on it again in navigation bar
